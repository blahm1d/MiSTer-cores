# Publishing instructions

Read `MAINTAINING.md` before changing or publishing this distribution.

Its ROM-download coverage checks are required for every new core and RBF/MRA
update. Verify upstream registration, generator/index coverage, unresolved games,
mirror publication, and live download results separately. Do not equate a working
core feed or an open upstream PR with automatic ROM availability.

Keep game ROM payloads out of this repository. Preserve source licenses, custom
MRA layouts, artifact identity, existing saves, and known-issue disclosures.

Publish under blahm1d, including commit author/committer and PR identity. Use
blahm1d-prefixed public branch names. Use only the publishing identity in public files and archives; omit alternate
account names and assistant branding. Retain required third-party credits.
